01 -- Screen Anatomy

Shows where each component slots into a typical screen. Use as spatial blueprint before building frames in Figma.

Student screens (ST-01 through ST-06)

1Nav bar (student accent)
2Status / alert banner (conditional)
3Stat tiles row
4Filter / tab bar
5
Main content area (cards / list)
6Action bar / primary CTA
1
Nav bar -- NTS logo, role pill (Student), nav links, username. Student blue accent underline on active link. Fixed height: 56px.
2
Status / alert banner -- Conditional. Appears when system status requires user attention. Uses status-banner component. Hidden when all clear.
3
Stat tiles -- At-a-glance metrics. 3 tiles max per row. Headset status, module progress, grade summary. Uses stat-tile component.
4
Filter / tab bar -- Present on list screens (ST-02, ST-06). Uses filter-bar component with student accent. Fixed height: 44px.
5
Main content area -- Scrollable. Card list or data table. 24px padding all sides. 12-column grid, 24px gutters. Content never touches viewport edges.
6
Action bar -- Sticky bottom on mobile, inline on desktop. Primary CTA button always rightmost. Cancel always left of confirm.

Lecturer screens (LC-01 through LC-08) -- same zones, green accent

Identical zone structure to student. Key differences: stat tiles show on-campus/remote split (LC-01), filter bar shows All/On-Campus/Remote/Flagged (LC-02), main content area uses student-tile grid on LC-05. Nav accent is lecturer green.

Admin screens (AD-01 through AD-10) -- priority-first layout

1Nav bar (admin accent)
2System status banner (always visible on AD-01)
3Priority issues -- above fold, always
4Stat tiles (headsets online, sessions, alerts, loans)
5
Main content (diagnostics table / firmware list / logs)
1
Nav bar -- Admin red accent. Links to Diagnostics, Firmware, Loans, Logs. Username top right.
2
System status banner -- Always visible on AD-01. Green/amber/red. Updates every polling interval. Never hidden on the dashboard.
3
Priority issues list -- MUST be above fold on AD-01. First thing Ruby sees. Sorted by severity. Max 3 rows visible without scrolling.
4
Stat tiles -- Headsets online, active sessions, priority alert count (red if >0), loan count. 4 tiles in a row.
5
Main content -- Scrollable. Live data rows for diagnostics. Table rows for firmware, loans, logs. Filter bar above table on all list screens.

02 -- Spacing & Grid Reference

All values are multiples of 8px. No arbitrary pixel values anywhere in the system.

Token scale

--sp1 4px Badge padding, tight gaps inside tags
--sp2 8px Component internal padding, gap between icon and label
--sp3 12px Small gaps between related elements, filter tab padding
--sp4 16px Standard component padding, card internal spacing
--sp5 24px Gap between components, card padding on larger screens
--sp6 32px Section spacing, gap between stat tiles and content area
--sp7 48px Large section breaks, page top padding
--sp8 64px Page-level side padding, max section separation

Spacing in context

Badge -- internal padding sp1 (4px) vertical, sp2 (8px) horizontal
